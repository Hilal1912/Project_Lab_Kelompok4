# Project_Lab_Kelompok4

Aplikasi Nasbak Cirebon (Nasi Bakar Ibu Efri)** adalah platform pemesanan makanan berbasis mobile yang dirancang untuk mempermudah alur transaksi kuliner secara digital. Aplikasi ini menghubungkan tiga pengguna utama (*Pelanggan*, *Admin*, dan *Kurir*) dalam satu ekosistem yang terintegrasi.

**Fitur Utama Berdasarkan Peran Pengguna**

**Sisi Pelanggan**
Eksplorasi Menu & Pemesanan: Menampilkan katalog menu nasi bakar dan minuman, pencarian menu, serta penambahan item ke keranjang belanja.
Opsi Layanan Flexibel: Mendukung metode transaksi *Dine-in* (makan di tempat), Take Away (ambil sendiri), dan Delivery (pengantaran).
Checkout & Profil: Manajemen alamat pengiriman, rincian pembayaran, serta halaman profil pengguna.

**Sisi Admin Panel**
Dashboard Monitoring: Menampilkan statistik total pesanan, pendapatan harian, ringkasan tipe pesanan, dan menu terlaris.
Manajemen Produk & Pesanan: Memungkinkan admin untuk mengelola katalog (tambah, edit nama/harga menu), memantau pesanan masuk, serta mengelola data pelanggan.
Laporan Penjualan: Laporan statistik berdasarkan rentang waktu tertentu untuk analisis bisnis.

**Sisi Kurir Tracker**
Daftar Pesanan Saya: Memisah daftar pesanan berdasarkan status pengantaran (Dalam Antrean, Dalam Proses, Dalam Perjalanan).
Detail & Alur Pesanan: Menampilkan alamat tujuan pengiriman beserta *timeline* status pengantaran secara riil.
Riwayat Pengantaran: Rekapitulasi pesanan yang telah selesai diantar oleh kurir.
